# Telegram-бот для заявок на вступление

[English](README.md) | **Русский**

Небольшой Telegram-бот, который отправляет личное сообщение-приглашение пользователям, подавшим заявку на вступление в чат или канал. Сделан для трейдинг-сообщества, чтобы превращать заявки на вступление в подписчиков основного канала.

## Возможности

- Обрабатывает события `chat_join_request` и отправляет пользователю в личные сообщения ссылку на основной канал.
- Не реагирует на заявки в целевой чат, чтобы тем, кто уже вступает в основной канал, приглашение не приходило.
- Команда `/online` для проверки, что бот работает.
- Настройка через переменные окружения (`.env`), токен не хранится в коде.
- Логирует отправленные сообщения и обрабатывает случаи, когда пользователь заблокировал бота или не запускал его.

## Стек

- Python 3.10+
- [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI) (telebot)
- python-dotenv

## Как это работает

1. Бот добавляется администратором в канал или группу, где включены заявки на вступление («Одобрение новых участников»).
2. Когда пользователь нажимает «Подать заявку», Telegram присылает боту событие `chat_join_request`.
3. Бот отправляет пользователю личное сообщение с текстом приглашения из [messages.py](messages.py).

## Запуск

```bash
git clone https://github.com/devuiandrew/tg-bot.git
cd tg-bot

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # затем впишите токен в .env
python tgbot.py
```

### Переменные окружения

| Переменная       | Обязательна | Описание                                                 |
|------------------|-------------|----------------------------------------------------------|
| `BOT_TOKEN`      | да          | Токен бота от [@BotFather](https://t.me/BotFather)        |
| `TARGET_CHAT_ID` | нет         | ID чата, заявки в который бот игнорирует                 |

## Настройка

Чтобы изменить текст приглашения, отредактируйте `JOIN_REQUEST_MESSAGE` в [messages.py](messages.py).
